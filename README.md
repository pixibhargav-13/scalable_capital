# Scalability Capital — Website

Strategic finance, advisory and private wealth.
Built with React, Vite and React Router.

## Pages

- **Home** — full-screen video hero, services, the SCALABLE framework, private wealth
- **Business** — six business finance services
- **Private Wealth** — capital allocation approach
- **Our Approach** — the SCALABLE framework
- **About** — philosophy and values
- **Insights** — featured article, category filters and six articles, each on its own page
- **Contact** — enquiry form, email, India and UAE numbers, WhatsApp

## Features

- Animated logo intro on first visit
- Self-hosted background video in the hero, with a lighter version for mobile
- Enquiry form delivered directly to info@scalabilitycap.com
- Floating WhatsApp button for the India and UAE numbers
- Sections fade in as the page scrolls
- Fully responsive, with a mobile navigation menu
- Respects reduced-motion accessibility settings
